# ADE Frontend Scope

ADE Web is the primary operator UI. It is a Next.js + TypeScript app at
`apps/ade-web/`; its same-origin `/api/...` proxy authenticates to the
`ade-api` service with a server-only credential.

## Maintained modules

- Dashboard
- Agent Studio
- Comment Lab
- Label Lab
- Schema Center
- Prompt Center
- Test Center
- API Docs

Prompt Center and Schema Center are the maintained content-editing surfaces; no
secondary frontend implementation owns their behavior.

## Runtime boundaries

- Agent Studio uses the ADE-owned native runtime at `/api/v3` for persistent
  definitions, memory subjects, conversations, memory layers, curated tools, and
  execution traces.
- Comment Lab and Label Lab are stateless generation workspaces.
- Prompt Center and Schema Center own reviewed workspace content and lifecycle
  operations.
- Test Center launches maintained checks/evals and reads run-scoped artifacts.
- Browser code never receives provider credentials or the ADE API key.
