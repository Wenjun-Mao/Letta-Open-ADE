# ADE Frontend Scope

ADE Web is the primary operator UI. It is a Next.js + TypeScript app at
`apps/ade-web/`; its same-origin `/api/v2/...` proxy authenticates to the
`ade-api` service with a server-only credential.

## Maintained modules

- Dashboard
- Agent Studio
- Comment Lab
- Label Lab
- Schema Center
- Prompt Center
- Tool Center
- Test Center
- API Docs

Prompt Center and Tool Center are the maintained editing surfaces; no secondary
frontend implementation owns their behavior.

## Runtime boundaries

- Agent Studio owns persistent Letta agents, memory layers, attached tools, and
  execution traces.
- Comment Lab and Label Lab are stateless generation workspaces.
- Prompt, schema, and tool centers own reviewed workspace content and lifecycle
  operations.
- Test Center launches maintained checks/evals and reads run-scoped artifacts.
- Browser code never receives provider credentials or the ADE API key.
