# ADE Frontend Scope

The ADE frontend is the primary operator UI. It is a separate Next.js +
TypeScript app whose same-origin `/api/v1/...` proxy authenticates to the
`agent_platform_api` backend with a server-only credential.

## Maintained modules

- Dashboard
- Agent Studio
- Comment Lab
- Label Lab
- Schema Center
- Prompt Center
- Tool Center
- Test Center
- API Docs

Legacy `/prompt-persona-lab` and `/toolbench` URLs redirect to their maintained
centers; they are not separate implementations.

## Runtime boundaries

- Agent Studio owns persistent Letta agents, memory layers, attached tools, and
  execution traces.
- Comment Lab and Label Lab are stateless generation workspaces.
- Prompt, schema, and tool centers own reviewed workspace content and lifecycle
  operations.
- Test Center launches maintained checks/evals and reads run-scoped artifacts.
- Browser code never receives provider credentials or the Agent Platform API key.
