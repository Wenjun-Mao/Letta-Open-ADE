# ADE 前端范围

ADE 前端是主要的运维界面。它是独立的 Next.js + TypeScript 应用，通过同源
`/api/v1/...` 代理，使用仅存在于服务端的凭据访问 `agent_platform_api`。

## 维护中的模块

- Dashboard
- Agent Studio
- Comment Lab
- Label Lab
- Schema Center
- Prompt Center
- Tool Center
- Test Center
- API Docs

旧的 `/prompt-persona-lab` 与 `/toolbench` 地址只负责重定向到对应 Center，
不再维护第二套实现。

## 运行边界

- Agent Studio 管理持久化 Letta 智能体、记忆层、已挂载工具与执行轨迹。
- Comment Lab 与 Label Lab 是无状态生成工作区。
- Prompt、Schema 与 Tool Center 管理经过审阅的工作区内容及其生命周期。
- Test Center 启动维护中的检查与评测，并读取每次运行独立的产物。
- 浏览器代码不会获得 Provider 凭据或 Agent Platform API Key。
