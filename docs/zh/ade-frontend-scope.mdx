# ADE 前端范围

ADE Web 是主要的运维界面。它位于 `apps/ade-web/`，是一个 Next.js +
TypeScript 应用，通过同源 `/api/...` 代理，使用仅存在于服务端的凭据访问
`ade-api` 服务。

## 维护中的模块

- Dashboard
- Agent Studio
- Comment Lab
- Label Lab
- Schema Center
- Prompt Center
- Test Center
- API Docs

Prompt Center 与 Schema Center 是维护中的内容编辑界面，不再保留第二套前端实现。

## 运行边界

- Agent Studio 通过 `/api/v3` 的 ADE 原生运行时管理持久化 Definition、Memory
  Subject、Conversation、记忆层、受控工具与执行轨迹。
- Comment Lab 与 Label Lab 是无状态生成工作区。
- Prompt Center 与 Schema Center 管理经过审阅的工作区内容及其生命周期。
- Test Center 启动维护中的检查与评测，并读取每次运行独立的产物。
- 浏览器代码不会获得 Provider 凭据或 ADE API Key。
