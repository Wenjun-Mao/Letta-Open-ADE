# ADE API（中文）

本文档介绍 ADE Web 与运维工作流使用的本地 ADE API。

## 环境假设

- 本地开发默认地址：
  - ADE Web：`http://127.0.0.1:3000`
  - ADE API：`http://127.0.0.1:8000`
  - Model Router 与 Letta：Compose 网络内部服务，不暴露宿主机端口。
- 浏览器请求通过 ADE 同源代理访问后端；直接 API 客户端使用 Reader、Operator
  或 Admin Bearer Key。
- 默认服务仅绑定回环地址，面向本地开发。公开部署仍需 TLS、托管密钥、限流、
  监控与威胁评审。

## 文档覆盖范围

- 面向智能体交互的运行时接口。
- 面向提示词、模型、记忆块与工具变更的控制接口。
- 两阶段安全删除生命周期（归档 -> 恢复 -> 清除）。
- 面向检查与 Runner 的测试编排接口。
- Comment Lab 与基于 Schema 的 Label Lab 无状态生成接口。
- Prompt、Persona、Schema 与自定义 Tool 生命周期接口。

## 智能体生命周期（安全删除）

建议采用以下两阶段删除路径：

1. 归档智能体（软删除，默认列表隐藏）
2. 如误操作可恢复
3. 清除已归档智能体（硬删除）

关键接口：

- `POST /api/v2/agent-studio/agents/{agent_id}/archive`
- `POST /api/v2/agent-studio/agents/{agent_id}/restore`
- `DELETE /api/v2/agent-studio/agents/{agent_id}/purge`
- `DELETE /api/v2/agent-studio/agents/{agent_id}`（清除已归档智能体的别名）
- `GET /api/v2/agent-studio/agents?include_archived=true`

行为说明：

- 默认情况下，`GET /api/v2/agent-studio/agents` 不返回已归档智能体。
- 对已归档智能体进行运行时或控制类变更会返回 `409`，需先恢复。
- 清除操作要求目标处于已归档状态，否则返回 `400`。

## 错误返回格式

FastAPI 返回的错误 JSON 结构如下：

```json
{
  "detail": "error message"
}
```

常见状态码：

- `400`: 请求不合法、状态流转不合法、参数校验失败
- `404`: 资源不存在
- `409`: 对已归档智能体执行了不允许的变更
- `503`: 必需运行时能力或上游依赖不可用

## 本地工作流

1. 重新导出 OpenAPI 英文产物：`uv run python scripts/export_openapi.py`
2. 重新生成 OpenAPI 中文产物（手工维护翻译）：`uv run python scripts/generate_openapi_zh_manual.py`
3. 当有重大变更时，手工更新 `docs/zh/` 下的中文文档页面
4. 仅检查英文 OpenAPI 漂移：`uv run python scripts/export_openapi.py --check`
