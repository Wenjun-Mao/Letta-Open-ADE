# ADE API（中文）

本文档介绍 ADE Web 与运维工作流使用的本地 ADE API。

## 环境假设

- 本地开发默认地址：
  - ADE Web：`http://127.0.0.1:3000`
  - ADE API v2：`http://127.0.0.1:8000`
  - ADE 原生 Agent Studio v3：`http://127.0.0.1:8002`
  - Model Router 与 Letta：Compose 网络内部服务，不暴露宿主机端口。
- 浏览器请求通过 ADE 同源代理访问后端；直接 API 客户端使用 Reader、Operator
  或 Admin Bearer Key。
- 默认服务仅绑定回环地址，面向本地开发。公开部署仍需 TLS、托管密钥、限流、
  监控与威胁评审。

## 文档覆盖范围

- ADE 原生 Agent Studio 的 Definition、显式 Memory Subject、Conversation、
  Turn、类型化 Memory、Summary、Run 与 Event 接口。
- Agent Studio Conversation、Definition 与 Subject 的归档/恢复，以及仅限
  Admin 的全新起点重置接口。
- 面向检查与 Runner 的测试编排接口。
- Comment Lab 与基于 Schema 的 Label Lab 无状态生成接口。
- Prompt、Persona、Schema 与自定义 Tool 生命周期接口。

## Agent Studio 生命周期

Agent Studio 将可复用行为、用户记忆归属与会话历史明确分离。一个 Session
会把一个不可变 Definition 版本绑定到一个 Memory Subject；归档 Conversation
不会删除 Subject Memory 或 Definition。

正常生命周期保持可恢复：

1. 创建或复用不可变 Agent Definition。
2. 创建或选择显式 Memory Subject。
3. 创建、归档或恢复 Conversation Session。
4. 独立于聊天检查类型化 Fact Revision 与来源消息证据。

关键接口：

- `GET|POST /api/v3/agent-studio/sessions`
- `GET|DELETE /api/v3/agent-studio/sessions/{conversation_id}`
- `POST /api/v3/agent-studio/sessions/{conversation_id}/restore`
- `GET /api/v3/agent-studio/sessions/{conversation_id}/state`
- `GET|POST /api/v3/agent-studio/definitions`
- `GET|POST /api/v3/agent-studio/subjects`
- `GET /api/v3/agent-studio/subjects/{subject_id}/memories`
- `POST /api/v3/conversations/{conversation_id}/turns`
- `GET /api/v3/runs/{run_id}/events`

行为说明：

- 默认列表不返回已归档资源；恢复前不能继续执行。
- Turn 异步执行并提供规范化 Run Event，不暴露模型私有推理或原始 Provider Body。
- 原生存储从全新状态开始，不提供 Letta 导入、双写、运行时切换或按请求回退。
- 保留的 v2 Letta 接口仅作为 Phase 5 的发布级回滚通道；切换后不再是浏览器主契约。

## 错误返回格式

FastAPI 返回的错误 JSON 结构如下：

```json
{
  "detail": "error message"
}
```

常见状态码：

- `400`: 请求不合法、状态流转不合法、参数校验失败
- `404`: 资源不存在
- `409`: 对已归档智能体执行了不允许的变更
- `503`: 必需运行时能力或上游依赖不可用

## 本地工作流

1. 重新导出 OpenAPI 英文产物：`uv run python scripts/export_openapi.py`
2. 重新生成 OpenAPI 中文产物（手工维护翻译）：`uv run python scripts/generate_openapi_zh_manual.py`
3. 当有重大变更时，手工更新 `docs/zh/` 下的中文文档页面
4. 仅检查英文 OpenAPI 漂移：`uv run python scripts/export_openapi.py --check`
