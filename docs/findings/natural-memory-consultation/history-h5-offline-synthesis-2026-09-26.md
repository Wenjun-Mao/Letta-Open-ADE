## Ambiguous Roxy referent: one linked trajectory

The [automatic target attempt](../../../workflows/evals/character_memory_dev/outputs/history-h4-final-remaining-live-20260926/attempts/b5a2d8bc-a1d3-469c-ba1f-188aa4ecc4c2/attempt-001.json) (`fd592fe1…`) admitted all three relevant H exchanges: the user described a black and a white dog, named the black dog Roxy, and named the white dog Nini. The held reviewer snapshot exposed active `F1=Roxy`/`E1=Roxy` and `F2=Nini`/`E2=Nini`. Its local U/A context and eligible support were empty at the target. The current user said only “它现在叫小黑。” The generation candidate identified the black dog as the referent while phrasing that identification as a confirmation question. The reviewer request exposed that candidate, H, F/E and the current quote; its decision revised `F1` to `小黑` with **direct** evidence `current_quote=它现在叫小黑。`. The committed revision cites that current quote as `user_assertion`, not an H or assistant source.

[Binding code](../../../services/ade-api/src/ade_api/features/agent_runtime/natural_memory_policy.py) checks that `F1` is a held active fact under this memory subject and binds the direct quote exactly. H handles are absent from U/A write support. Thus the captured write passed the **structural** authority rules; it is not evidence that H was accepted directly as write support. The fixture expected deferral because “它” could name either pet. The model's F1 selection is a material **semantic referent inference** from an ambiguous current assertion. H and the candidate both contained the black-dog/Roxy association, but the capture cannot isolate which influenced the reviewer or its internal reasoning. There was no local prior assistant at target time; the historical assistant's “Roxy 是黑色那只” was read-only H data.

The [empty-history target](../../../workflows/evals/character_memory_dev/outputs/history-h4-final-remaining-live-20260926/attempts/18f470f6-a85f-47b1-9624-f96421874365/attempt-001.json) deferred and asked which pet was renamed. On explicit followup (“我是说以前那只叫 Roxy 的黑狗，现在叫小黑。”), it revised Roxy. In the automatic trajectory the target had already revised Roxy, so the explicit [followup](../../../workflows/evals/character_memory_dev/outputs/history-h4-final-remaining-live-20260926/attempts/4dd33a86-4564-4653-8625-588cea6e6e55/attempt-001.json) returned `decisions: []` against the now-`小黑` held fact.
